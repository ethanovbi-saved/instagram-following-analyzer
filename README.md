# Instagram Following Analyzer

A Python tool that analyzes Instagram follower and following data to identify accounts that do not follow you back and track changes across multiple Instagram data exports.

The program maintains a persistent list of accounts you intentionally choose to keep following, detects changes between exports, and provides an interactive review process for managing newly identified accounts.

## Features

- Identifies accounts you follow that do not follow you back.
- Compares current and previous Instagram exports to detect changes over time.
- Maintains a persistent keep-following list for accounts you intentionally choose to follow despite no reciprocation
- Provides an interactive review process for newly identified accounts.
- Distinguishes between accounts marked for review and accounts skipped for the current session.
- Detects accounts that are no longer followed and allows them to be removed from the keep-following list.
- Generates a review list containing usernames and profile links for easy follow-up.

## How It Works

The analyzer uses two Instagram data exports:

- **Export 0** serves as the baseline and represents an earlier snapshot of your follower and following data.
- **Export 1** represents your most recent Instagram data and is compared against the baseline.

Using these exports, the program identifies accounts that require review and presents them interactively.

For each account, the user can choose:

- **Y (Yes):** Keep following the account. The username is added to `keep_following.txt` and will not be repeatedly flagged in future analyses.
- **N (No):** Leave the account for review. It appears in `review_list.txt` with a `[REVIEW]` label.
- **S (Skip):** Skip the decision for the current session. It remains in `review_list.txt` with a `[SKIP]` label.

The program also detects usernames stored in `keep_following.txt` that are no longer present in the current following data and gives the user the option to remove them.

Personal Instagram data and generated output files were excluded from version control through `.gitignore`.

## Installation & Setup

### 1. Download the Project

Clone or download this repository to your computer.

Python 3 is required to run the analyzer. The project uses only Python's standard library, so no additional packages need to be installed.

### 2. Download Your Instagram Data

Request a JSON export of your Instagram follower and following information (I recommend only deselecting all other options expect "Followers and Following") through Instagram's Accounts Center.

Once the export is available, locate the following files:

- `followers_1.json`
- `following.json`

### 3. Set Up the Baseline Export

Place your first set of Instagram data inside:

```text
data/export_0/
```

This export serves as the baseline used by the analyzer.

### 4. Add the Current Export

Place your newer Instagram data inside:

```text
data/export_1/
```

The analyzer compares this export with the baseline to identify changes.

### 5. Create the Keep-Following File

Inside the `data` directory, create:

```text
keep_following.txt
```

This file stores usernames for accounts you intentionally choose to keep following even if they do not follow you back.

### 6. Run the Analyzer

From the project directory, run:

```bash
python3 analyzer.py
```

Follow the prompts in the terminal to review the identified accounts.

## Output

After reviewing the detected accounts, the program generates:

- `keep_following.txt` — stores accounts you intentionally choose to keep following.
- `review_list.txt` — stores accounts that still need attention.

Accounts in `review_list.txt` are labeled as:

- `[REVIEW]` — accounts you chose not to keep following.
- `[SKIP]` — accounts you skipped for the current session and may want to review later.

The review list also includes profile URLs when available.

## Privacy

This project is designed to work with personal Instagram export data locally on your computer.

Real Instagram follower data, following data, keep-following lists, and generated review files are excluded from Git through `.gitignore` and should not be uploaded to a public repository.

Users should avoid committing personal Instagram export files or generated account lists to GitHub.
